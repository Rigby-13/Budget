# Бюджет — личный учёт расходов (PWA)

Веб-приложение для iPhone: добавляется на экран «Домой», работает офлайн,
все данные хранятся только на телефоне (IndexedDB). Без сервера и регистрации.

## Структура

```
index.html            — разметка всех экранов
css/style.css         — внешний вид (светлая/тёмная тема, safe area)
js/app.js             — логика интерфейса
js/db.js              — работа с базой IndexedDB
js/utils.js           — форматирование рублей и дат
js/ui.js              — общие элементы: выезжающие панели, сообщения
js/debts.js           — вкладка «Долги»
js/backup.js          — резервная копия (экспорт/импорт JSON)
js/categories.js      — свои категории и лимиты
js/stats.js           — статистика: диаграммы, периоды
js/plan.js            — шаблоны планов, план месяца, лимиты: расчёты, перенос, итоги
js/planui.js          — вкладка «Лимит», выбор шаблона, карточка плана, итоги месяца
js/testmode.js        — тестовый режим и «машина времени»
js/savings.js         — накопления: копилка, итоги месяцев
js/wallet.js          — «Мои деньги»: текущий остаток
js/guide.js           — гайд при первом открытии
js/importparse.js     — чтение выписки: CSV и Excel (.xlsx)
js/importer.js        — импорт выписки: колонки, категории, повторы, «Не распознано»
js/importpdf.js       — чтение PDF-выписок (Сбербанк и общий формат)
js/reset.js           — удаление записей за месяцы / всё время, полный сброс
js/theme.js           — оформление: стиль (Классика / Лес / Огород) и тема
fonts/                — шрифт Unbounded (SIL OFL) для стилей «Лес» и «Огород»
vendor/pdfjs/         — библиотека pdf.js (Mozilla) для чтения PDF
sw.js                 — service worker (офлайн-режим)
manifest.webmanifest  — описание приложения для экрана «Домой»
icons/                — иконки
```

## Публикация на GitHub Pages

1. Откройте репозиторий на github.com → **Settings** → **Pages**.
2. В разделе **Build and deployment** → **Source** выберите **Deploy from a branch**.
3. В **Branch** выберите ветку с кодом (`main`, когда изменения будут влиты туда)
   и папку **/ (root)** → **Save**.
4. Через 1–2 минуты сверху появится адрес вида `https://<логин>.github.io/<репозиторий>/`.

> На бесплатном тарифе GitHub Pages работает только для **публичных** репозиториев.
> Это безопасно: в репозитории лежит только код, ваши траты остаются на телефоне.

## Установка на iPhone

1. Откройте адрес в **Safari**.
2. Кнопка «Поделиться» → **На экран «Домой»** → **Добавить**.
3. Запускайте с иконки — приложение откроется на весь экран и будет работать без интернета.

## Как обновлять

1. После изменений увеличьте `VERSION` в `sw.js` и номер «Версия N» в настройках (`index.html`).
2. После публикации (1–2 минуты) откройте приложение — при наличии интернета оно
   само подтянет новую версию и один раз перезагрузится.
